# 1. Record architecture decisions

Date: 2026-10-11

## Status

Accepted

## Context

We want future contributors (and any future owner of the project) to understand why things are
the way they are.

## Decision

We record significant decisions as short numbered ADRs in `docs/decisions/`, using the template:
Context, Decision, Consequences.

## Consequences

Decisions are reviewable in pull requests and stay with the code.
